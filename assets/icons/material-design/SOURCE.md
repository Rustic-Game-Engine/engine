# Material Design Icons source

These SVG files are downloaded directly from the
[Iconify Material Design Icons collection](https://icon-sets.iconify.design/mdi/).
Each request uses Iconify's `color=#FFFFFF` option so egui can tint the source
glyph to the active light or dark theme foreground color without a black base
fill suppressing the tint.

The glyphs come from the Pictogrammers Material Design Icons pack. The included
`LICENSE` is that upstream icon-pack license.
