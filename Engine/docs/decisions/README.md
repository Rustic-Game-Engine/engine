# Architecture decision records

Use a zero-padded sequence and short slug, for example
`0001-example-platform-boundary.md`. Accepted records are append-only; superseding a
decision links the old and new records.

```markdown
# ADR-NNNN: Decision title

Status: proposed | accepted | superseded
Date: YYYY-MM-DD

## Context and observed problem

## Decision

## Migration impact

## Rollback plan

## Evidence
```
